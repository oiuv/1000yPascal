一、项目概述与技术栈

项目名称：千年（1000y / Thousand Years）— 炎黄新章 D7 修复版

项目性质：经典韩国武侠 2D MMORPG 的完整服务端 + 客户端源码

游戏特色：完整的武侠 RPG 体系 — 门派/武功/绝学/元气/阴阳/炼丹/采矿/结婚/竞技场

建议的部署边界

客户端只需访问 Balance(3053) 和 Gate(3054)。生产环境应通过防火墙把其余服务限制在内网；源码不能证明服务器当前的实际公网暴露状态。

四、游戏服务器核心 (TGS1000)

运行模型：单进程 + Timer 驱动

核心是 10ms 间隔的主游戏循环 TimerProcess，每 tick 轮询更新所有子系统：

TFrmMain.TimerProcess (每10ms) ├── GateConnectorList.Update() ← Gate 网关通信 ├── ConnectorList.Update() ← 连接管理 ├── UserList.Update() ← 玩家更新 ├── ManagerList.Update() ← 地图/怪物/NPC 更新 ├── GuildList.Update() ← 帮会 ├── ArenaObjList.Update() ← 竞技场 ├── Zhuang.Update() ← 庄园 ├── ScriptManager.Update() ← 脚本引擎 └── ... 其他子系统 (监狱/天气/音效/区域效果)

五、登录认证流程

完整登录流程

阶段1: 客户端 ──→ Balance (TCP:3053) └─ 遍历所有Gate，选 UserCount 最小的 → 返回Gate地址 阶段2: 客户端 ──→ Gate (TCP:3054) └─ Gate 创建 TConnector，状态 gs_none 阶段3: 登录认证 └─ Gate ──→ Login (TCP:3050) 发送 LG_SELECT └─ Login 使用自身的 MSSQL/SDB 账号适配器返回 TLGRecord └─ Gate 验证 PrimaryKey + PassWord └─ Gate 更新账号登录信息并校验 Paid 状态 阶段4: 角色选择/创建 └─ 创建: Gate ──→ DB (TCP:3051) 发送 DB_CREATENEW └─ 选择: Gate ──→ DB 发送 DB_SELECT，验证归属 阶段5: 进入游戏 └─ Gate 附加付费数据 ──→ Game (TCP:3052) 发送 GM_CONNECT └─ Game 确认 → Gate 发送 DB_LOCK 锁定角色 └─ 状态切换为 gs_playing，此后数据透传

网关状态机

游戏状态: gs_none → gs_login → gs_none → gs_selectchar → gs_gotogame → gs_playing 窗口状态: cw_none → cw_login → cw_selectchar → cw_main 说明: gs_agree/cw_agree 仅在枚举中声明，当前 Gate 流程未使用；GameAgree.TXT 由 Game Server 处理。 超时机制: • 非游戏状态 60秒无响应 → 发送 [TIMEOUT] • 非游戏状态 5分钟 → 强制断开 • 每秒包频率 > 10 → 强制断开

FDB 文件格式

文件头 (TDBHeader): ID: "DBID" (4 bytes) RecordCount: Integer RecordDataSize: Integer RecordFullSize: Integer (单条 TDBRecord 的完整存储大小) 索引头 (TIndexHeader): IndexRecordCount · BlankRecordCount · FDBUpdateDate 数据区: 连续 packed record，预分配 10,000 条空白记录 操作接口: TDBProvider (Insert / Select / Update / Delete)

八、安全机制与风险

机制实现方式风险
网络加密自定义类Base64 (LCG随机种子=1 + Fisher-Yates洗牌)⚠️ 中 — 随机种子为常量，加密表可还原
服务器授权源码保留 SHA1+AES 硬件指纹及注册表工具，但 Game 的拒绝/关闭逻辑已注释，DB 和 Balance 中未找到执行授权判断的代码🔴 未强制执行
IP 白名单IPList.txt 文件加载⚠️ 中 — 文件缺失时放行所有连接
包频率限制滑动窗口，每秒≤10包✅ 有效
数据完整性CRC32 校验 (TDBRecord.CRCKey)✅ 基本有效
SQL 注入防护分号/单引号检查⚠️ 中 — 仅基础防护，使用字符串拼接SQL
角色名过滤DONTCHAR.TXT 禁用列表✅ 有效
密码存储明文存储🔴 高风险
SimplePass固定偏移数组位移替换🔴 高风险 — 等同无加密

九、关键发现与总结

🏗️ 架构特点

  • 经典 MMORPG 分层架构，职责分离清晰
  • 网关中心化，Gate 是所有通信的核心枢纽
  • 单线程 Timer 驱动 (10ms)，简单可靠
  • 九宫格 AOI，高效的场景消息分发
  • 脚本驱动，Pascal 脚本热更新

  • 完整的武侠 RPG 系统
  • 60+ 种物品类型
  • 165+ 个 NPC 脚本

  • 密码改用 bcrypt/argon2 哈希

  • IP白名单文件缺失时拒绝所有
  • 加强授权码存储保护
