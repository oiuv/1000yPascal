# usemagicgradeup

提升当前触发玩家正在使用的绝世武功品级。

## 语法

```pascal
print('usemagicgradeup <Type> <TargetGrade>');
```

| `Type` | 当前实现 |
| ---: | --- |
| `0` | 当前绝世护体武功 |
| `1` | 当前绝世攻击武功 |
| `2` | 分支存在但为空，不执行升级 |
| `3` | 通过范围检查，但 `case` 中没有分支，不执行升级 |

`TargetGrade` 只接受 0..2；有效升级还要求当前武功修炼值为 9999，且 `当前 rGrade + 1 = TargetGrade`。成功后 `rGrade` 加 1、修炼经验清零、重新加载对应循环数据并通知客户端；攻击武功升级还可能增加可分配属性点。

该方法没有检查或扣除物品、钱币。命令调用忽略内部 Boolean 返回值，失败时通常表现为没有升级。
