# 云端千年神武奇章线上优化版脚本归档

本目录保存用户实际运营的“云端千年神武奇章”服务器脚本。该版本以原版神武奇章核心玩法为基础，并加入运营优化；活动、奖励、对象配置和文案可能属于云端版定制，不能据此反推原版神武奇章或当前炎黄新章的行为。197 个 `.txt` 文件及 `Script.SDB` 保持原始 **GBK/CP936、CRLF** 格式；不要批量转成 UTF-8。

## 与当前源码的关系

- `docs/Script/`：云端千年神武奇章线上优化版实例，只能证明该运营版本怎样部署和调用。
- `gameserver-tgs1000/bin/Script/`：当前仓库未修改的炎黄新章随包脚本。
- `gameserver-tgs1000/uScriptManager.pas`、`ScriptCls.pas`：当前接口注册、参数分派和解释器行为的最终标准。

炎黄新章是后续版本，但同名脚本不一定内容相同。当前对比结果：两边有 164 个同名数据文件（含 `Script.SDB`），其中 60 个字节相同、104 个不同；本目录另有 34 个云端版独有 `.txt`，炎黄目录另有 `火炉1.txt`。这些差异既可能来自版本演进，也可能来自云端运营优化，不能仅凭文件差异归因。

## 兼容性注意

云端版脚本不能整目录直接覆盖到当前炎黄服务器。已确认的差异包括：

- 云端神武版和炎黄随包的 `龙师父.txt` 都使用 `callfunc('getjobgrade')`，但当前 `TScriptManager.CallFunction` 没有此分支，应改用 `getsenderjobgrade`；
- 云端神武版脚本会给 `getrandomitem` 传入 4、5，当前炎黄源码只为 0～2 分配列表；炎黄随包虽然还有编号 3 的数据和调用，源码本身也存在越界矛盾。
- 云端神武版的 `一级雨中客.txt`、`比武雨中客.txt`、`迷宫老侠客.txt` 使用合法的 `say 文本`，炎黄随包对应行却写成 `say文本`，不会命中当前命令分派；两版 `绣球.txt` 还有两处直接把普通文本交给 `print`，同样没有对应命令。

这说明“随包存在”或“函数名仍注册”都不等于参数范围一定兼容，仍须回查当前分派器和数据结构。随机池细节见 [Event 运行数据](../help/Event.md)。

复制示例前依次确认：

1. `print`/`callfunc` 名称在当前分派器中仍然注册；
2. `Self`、`Sender` 与事件触发路径一致；
3. 对象名、地图名、脚本编号同时存在于当前 `Init`、`Setting` 和 `Script.SDB`；
4. 示例中的 `Help`、`NpcSetting` 及物品名称在当前版本存在。

技术文档引用这里的代码时，应标注“云端千年神武奇章线上优化版脚本”；引用当前 `bin` 时标注“未修改的炎黄新章随包脚本”。
