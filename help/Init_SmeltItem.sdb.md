# SmeltItem.sdb

冶炼物品数据配置文件（矿石→材料），定义从原石冶炼为成品材料的配方，包括所需原料和费用。

## 文件路径

```
.\Init\SmeltItem.SDB
```

## 文件格式

CSV 格式，逗号分隔，首行为列名。

## 字段说明

| 列名 | 类型 | 说明 | 源码依据 |
|------|------|------|----------|
| Name | String | 冶炼产物名称（主键，如"钢铁"、"青铜"等） | `StrPCopy(@psd^.rName, iName)` |
| NeedItem | String | 所需原料，格式为"原料名:数量" | `Str := GetValidStr3(Str, ItemName, ':')` → `psd^.rNeedItem`; `psd^.rNeedCount := _StrToInt(ItemCount)` |
| Price | Integer | 冶炼费用 | `psd^.rPrice := DB.GetFieldValueInteger(iName, 'Price')` |
